ContractMind v1.5 Complete Platform Rundown

Autonomous Legal AI Architecture & Feature Overview for New Users

Cyclic StateGraph Multi-Agent Architecture LangGraph Core

Contracts are processed through a cyclic debate between 3 specialized AI agents: Auditor Agent (identifies non-compliant clauses), Opposing Counsel Agent (defends counter-party interests), and Arbiter Agent (synthesizes market-standard consensus redlines).

1. Ingestion & Contextual RAG

PyMuPDF extracts full contract sections. Text is chunked and indexed into an in-memory vector store for sub-second legal retrieval.

2. Multi-Engine & Local Ollama

Powered by Google Gemini 3.5 Flash Lite (Cloud) and Local Ollama (qwen3.5:4b). Live status pills confirm connectivity.

3. Negotiation Playbooks

Choose from Standard Corporate (balanced 1x caps), Aggressive Startup (relaxed caps to close deals), or Vendor Friendly (protects IP).

4. Word Track Changes (.DOCX)

Generates genuine native Microsoft Word Track Changes XML markup with strike-through deletions, underlines, and inline legal rationale comments.

5. Structured Obligations Matrix

Automatically extracts contractual duties, obligor/recipient roles, calendar triggers, and breach penalties into clean tabular data.

6. 6 Benchmark Test Datasets

Pre-loaded with Tech M&A, Cloud DPA, Strategic Joint IP, Enterprise MSA, SaaS Agreement, and Mutual NDA for one-click testing.
